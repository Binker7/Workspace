# Workspace

Write-ups of systems I have designed, built and deployed as an IT administrator.

Each case study covers the problem, the design decisions and why I made them, how I tested the system, and how it was deployed and documented. They are sanitized: no organization names, hostnames, IP addresses, tenant or application IDs, account names, configuration exports or regulated data. Code written on the job is treated as the employer's property and is not published here unless I have permission to share a generic version.
